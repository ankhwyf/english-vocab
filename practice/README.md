# 每篇练习（一课文一个 HTML）

这里放**每篇课文配套的练习题**，一篇一个文件，**永不覆盖旧文件**。
文件名格式：`YYYY-MM-DD-书名.html`（书名里的空格换成 `-`）。

打开方式：双击，浏览器直接跑，不用联网、不用起服务。
答题状态存在浏览器 localStorage 里，文件名不同就各存各的，不会互相干扰。

**导出错题**：每个页面顶部有「导出错题」按钮。点一下会把做错的题（题干、你的答案、正确答案、解析）
导出成 txt 到下载目录，同时复制到剪贴板。把文件拖进对话、或直接粘贴内容，就能针对错题出专项练习。

`../practice.html` 是**另一件事**：它不针对某一篇，是拿整个 `words.json`（255 词）
抽题背单词的通用练习器。新增课文时不需要动它。
