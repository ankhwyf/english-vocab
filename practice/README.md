# 每篇练习（一课文一个 HTML）

这里放**每篇课文配套的练习题**，一篇一个文件，**永不覆盖旧文件**。
文件名格式：`YYYY-MM-DD-书名.html`（书名里的空格换成 `-`）。

打开方式：双击，浏览器直接跑，不用联网、不用起服务。
答题状态存在浏览器 localStorage 里，文件名不同就各存各的，不会互相干扰。

`../practice.html` 是**另一件事**：它不针对某一篇，是拿整个 `words.json`（240 词）
抽题背单词的通用练习器。新增课文时不需要动它。
